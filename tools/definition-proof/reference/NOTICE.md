# T3Personal source fixture

`t3personal.settings.kts` is the original `.teamcity/settings.kts` from
[`iXab3r/t3code` at 7ff65cada80dd817aa5d7467b85e78ec30c578a9](https://github.com/iXab3r/t3code/blob/7ff65cada80dd817aa5d7467b85e78ec30c578a9/.teamcity/settings.kts).
Its original LF Git blob is `2eccef048973d5151c93aba0df0b96c913bfd20d` (5,046 bytes).
The independently captured historical settings revision is
`7495b6859c91952ad91478a2428be805a4e48f1a`; those settings bytes are identical.
The test normalizes checkout CRLF to LF before verifying original Git blob identity.

This is a reference fixture, never an activated configuration or executed workload. Its launch-check
and production-repository names retain their historical meaning. `T3Recipe.cs` translates its explicit
product declarations; stable step IDs are attributed experiment IDs. Implicit TeamCity defaults,
full runner behavior and script adaptation are separate evidence obligations.
