# Role-design phases

1. [x] Freeze role names, ownership boundaries, and focused document targets.
2. [x] Draft canonical role guides and domain design documents independently.
3. [x] Reconcile cross-cutting Git, REST, security, logging, persistence, scheduling, and documentation rules.
4. [x] Add role indexes and thin Codex/Claude adapters; update the root router and numbered architecture decisions.
5. [x] Rerun the inventory, validate links and contradictions, and record final evidence and handover.

The workstream closes only when every role has one canonical guide, every domain role has one focused
design document, both harness adapters exist, shared architecture agrees with the focused documents, and
the generated inventory has no unclassified item. All gates are closed.
